Weekly Review

A Claude skill that closes your week on one page: what got done, where the time went, what slipped, and three priorities for next week.

Install the skillView the source

Free and open source. Works in Claude Code and in the Claude apps.

What you get

Done

Outcomes of the week, not activity

Time

Hours in meetings, biggest blocks, longest free stretch

Slipped

Overdue tasks and people still waiting for an answer

Next week

Three proposed priorities, each with a first step

Install

git clone https://github.com/AdrienBalcioglu/weekly-review.git ~/.claude/skills/weekly-review

Then type /weekly-review in Claude Code. In the Claude apps, download SKILL.md from the repository, zip it in a folder named weekly-review, and upload it in Settings → Capabilities → Skills.

Private by design

Read-only: the skill never sends, replies, accepts or archives anything. It stores nothing and reads everything fresh on each run.
